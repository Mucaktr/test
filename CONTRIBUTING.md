# Contributing

Start with an issue describing the task, expected behavior, actual result, host/version,
and a minimal redacted example. Do not include credentials, private conversations, or client code.

Keep changes scoped. Separate instruction changes from packaging/documentation changes.
Explain the evidence needed for behavior claims; a package check alone does not demonstrate them.
Run `python -X utf8 scripts/check_package.py` after rebuilding the ZIP when packaged files change.

Contributions are provided under this repository's MIT license.
