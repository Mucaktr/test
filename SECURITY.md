# Security

Do not publish secrets or exploitable private-target details in public issues.
Use GitHub's **Security → Advisories → Report a vulnerability** if private reporting
is available for this repository. If it is unavailable, open a minimal issue asking
the maintainer for a private reporting channel without disclosing the vulnerability.

This instruction-based skill is not an isolation or enforcement boundary.
The host's system rules, permissions, and sandbox remain authoritative.
The packaging prerelease has no production-security or compatibility certification.
